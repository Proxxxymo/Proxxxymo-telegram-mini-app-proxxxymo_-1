## 2024-08-29 - System Dark Mode in Vanilla HTML/JS
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements.
**Action:** Always add this meta tag when creating or maintaining vanilla HTML Telegram Mini Apps to ensure proper rendering across different device themes without needing a custom CSS setup.
