## 2026-09-12 - Enable Native Dark Mode
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, the `<meta name="color-scheme" content="light dark">` tag in the HTML `<head>` natively enables system dark mode support for default HTML elements.
**Action:** Always include this meta tag in vanilla web apps to ensure basic accessibility and responsiveness to the user's system preferences without relying on heavy custom CSS.
