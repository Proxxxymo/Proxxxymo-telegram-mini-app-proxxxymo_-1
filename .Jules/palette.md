## 2026-08-27 - Native Dark Mode in Vanilla Telegram Web Apps
**Learning:** In vanilla HTML/JS Telegram Mini Apps, custom CSS should be avoided. Rely on native browser features where possible to integrate smoothly with the platform.
**Action:** Use `<meta name="color-scheme" content="light dark">` in the HTML `<head>` to natively enable system dark mode support for default HTML elements without adding custom styles.
