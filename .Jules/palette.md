## 2026-09-06 - System Dark Mode Support
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements.
**Action:** Always add this meta tag to the base HTML of vanilla Telegram Mini Apps to ensure immediate compatibility with the user's Telegram theme preference without requiring custom CSS.
