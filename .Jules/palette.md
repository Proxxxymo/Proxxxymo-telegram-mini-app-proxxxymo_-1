## 2026-09-15 - Native System Dark Mode Support
**Learning:** In vanilla HTML/JS applications, custom CSS is sometimes avoided. To natively enable system dark mode support for default HTML elements (like background color and text color), use `<meta name="color-scheme" content="light dark">` in the HTML head.
**Action:** Add this meta tag to `index.html` to instantly improve accessibility for users who prefer dark mode, without writing custom CSS.
