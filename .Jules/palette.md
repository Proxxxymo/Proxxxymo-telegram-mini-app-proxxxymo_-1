## 2026-09-22 - Native Dark Mode for Vanilla Web Apps
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements.
**Action:** Always add this meta tag to simple HTML files to ensure native elements adapt to the user's Telegram theme preference without needing custom CSS.
