## 2024-05-24 - Native Dark Mode Support in Vanilla HTML
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, we can use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements. This dramatically improves the UX and accessibility for users with dark mode preferences without requiring explicit CSS styling for every element.
**Action:** Always include `<meta name="color-scheme" content="light dark">` in the `<head>` of vanilla HTML applications to ensure base-level dark mode support.
