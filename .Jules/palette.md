## 2024-03-22 - Native Dark Mode in Telegram Web Apps
**Learning:** In vanilla HTML/JS Telegram Mini Apps where custom CSS is avoided, we can natively enable system dark mode support for default HTML elements by simply adding `<meta name="color-scheme" content="light dark">` to the HTML `<head>`.
**Action:** Use the `color-scheme` meta tag in vanilla web apps to get native dark mode styling for free.
