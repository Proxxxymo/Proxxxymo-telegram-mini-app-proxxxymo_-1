## 2024-05-24 - Native Dark Mode via Meta Tag
**Learning:** In vanilla Telegram Web Apps without a custom design system, using `<meta name="color-scheme" content="light dark">` allows the browser to natively handle dark mode styling for default UI elements (like backgrounds, text, buttons) based on the user's OS/device preferences. It's a zero-CSS way to immediately improve accessibility and UX in simple apps.
**Action:** Always consider adding this meta tag for simple vanilla HTML/JS projects to get baseline dark mode support before writing any custom CSS.
