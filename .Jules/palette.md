## 2024-06-25 - Support Native Dark Mode in Vanilla Web Apps
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements.
**Action:** When working with vanilla HTML in Telegram Web Apps without styling libraries, apply the `color-scheme` meta tag to ensure default form elements, buttons, and backgrounds respect the user's OS or Telegram theme preference.
