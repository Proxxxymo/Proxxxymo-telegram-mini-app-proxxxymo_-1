## 2026-08-09 - Native System Dark Mode Support
**Learning:** In vanilla Telegram Web Apps where custom CSS is avoided, the default HTML elements might not automatically adapt to the user's system dark mode, causing a jarring visual experience or accessibility issues.
**Action:** Use `<meta name="color-scheme" content="light dark">` in the HTML head to natively enable system dark mode support for default HTML elements without adding custom CSS.
