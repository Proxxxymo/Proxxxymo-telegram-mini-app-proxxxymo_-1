## 2026-08-16 - Native Dark Mode in Vanilla HTML Telegram Web Apps
**Learning:** In vanilla HTML/JS Telegram Mini Apps, it's possible to support the system dark mode without custom CSS by using the `<meta name="color-scheme" content="light dark">` tag in the `<head>`, making the app instantly more accessible.
**Action:** Always verify if a simple HTML/JS app has a `color-scheme` meta tag and add it to immediately support system-level dark mode styles for default HTML elements.
