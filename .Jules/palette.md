## 2026-08-19 - Native Dark Mode in Telegram Web Apps
**Learning:** In vanilla HTML/JS Telegram Mini Apps, it's possible to support dark mode without relying on external CSS frameworks or writing custom styles. Simply adding a `<meta name="color-scheme" content="light dark">` meta tag in the HTML head allows default UI elements to adapt natively to the Telegram application's light and dark themes. This provides immediate accessibility benefits and better integration with the Telegram ecosystem without increasing complexity or file size.
**Action:** Always include the `<meta name="color-scheme" content="light dark">` tag in the `<head>` of Telegram Web Apps to natively support default HTML elements adapting to light/dark themes natively via the user's OS and Telegram client.
